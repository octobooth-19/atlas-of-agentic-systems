## Platform

## Users
*(Inferred from brief)* Engineers, AI researchers, architects, and builders exploring how autonomous AI agents are structured, orchestrated, and connected.

## Product Purpose
*(Inferred from brief)* An interactive spatial atlas that maps the landscape of AI agent architectures, orchestration topologies, memory/tool loops, communication protocols, and failure modes so visitors can explore, compare, and trace how modern agents work.

## Positioning
*(Inferred from brief)* Instead of a static blog post or linear glossary, the atlas treats agent engineering as a navigable cartographic territory—connecting architectures, protocols, and execution loops with interactive inspection, live-feeling signal tracing, and side-by-side comparison.

## Operating Context
*(Inferred from brief)* Opened directly in a desktop or mobile browser as a standalone single-file `index.html` web application with zero external package downloads or build steps.

## Capabilities and Constraints
- *(Inferred from brief)* Single-file `index.html` (plain HTML, CSS, and JavaScript, zero external npm/Python dependencies; offline-capable without CDN-required JS frameworks).
- Interactive pan/zoom or spatial territory navigation with filtering by domain/layer, search, node inspection drawer, and animated execution/handoff path tracing.
- Must label all inferred product facts clearly until confirmed.

## Product Principles
1. **Spatial clarity over text walls:** Every concept lives in a meaningful region with visible relationships to neighboring patterns.
2. **Inspectable depth:** Clicking any node reveals concrete mechanics, trade-offs, failure modes, and canonical loop pseudocode without cluttering the map.
3. **Interactive simulation:** Visitors can trace execution flows (e.g., ReAct loop, Supervisor-Worker handoff, MCP tool call) directly on the atlas.
4. **Self-contained durability:** Runs cleanly from `file://` or a local static server with no external runtime dependencies.
